# 영상처리 기말 프로젝트 — x4 초해상화

영상처리 강의 개념으로 초해상화 베이스라인(ESPCN)의 약점을 찾아 고치고, 같은 조건에서 학습한 자기 베이스라인 대비 효과를 실험으로 입증하는 2인 팀 프로젝트의 공용 언어.

## 영상과 과제

**초해상화**:
LR 영상으로부터 배율만큼 큰 HR 영상을 추정하는 과제. 이 프로젝트에서는 단일 영상, 배율 4로 한정한다.
_Avoid_: 업스케일링, 화질 개선, 해상도 향상

**HR 영상**:
평가의 정답이 되는 고해상도 원본 영상.
_Avoid_: 원본, 정답 이미지, GT, 타깃

**LR 영상**:
HR 영상에 열화 모델을 적용해 만든 저해상도 입력 영상.
_Avoid_: 저화질 이미지, 입력 이미지, 축소본

**SR 결과**:
어떤 구성이 LR 영상으로부터 만들어 낸 고해상도 출력 영상.
_Avoid_: 복원 이미지, 예측 이미지, 출력

**배율**:
HR 영상과 LR 영상의 가로·세로 크기 비율. 이 프로젝트에서는 항상 4.
_Avoid_: 스케일, 확대율, 업샘플 비율

**열화 모델**:
HR 영상에서 LR 영상을 만드는 규칙. 이 프로젝트의 기본 열화 모델은 bicubic 축소다.
_Avoid_: 다운샘플링 방식, 손상, 저하 방식

**패치**:
학습에 쓰는, 위치가 서로 대응하는 HR 영상과 LR 영상의 작은 영역 한 쌍.
_Avoid_: crop, 타일, 조각 이미지

**패치 풀**:
DIV2K 학습셋에서 한 번 만들어 모든 실행이 공유하는 패치 전체 집합. 실행마다 달라지는 것은 시드에 따라 풀에서 뽑는 패치와 순서뿐이다.
_Avoid_: 패치 세트, 학습 데이터셋, 캐시

**테스트셋**:
성능 보고에 쓰는 고정된 평가용 영상 묶음: Set5, Set14, BSD100, Urban100.
_Avoid_: 벤치마크, 평가 데이터, 검증셋

## 모델과 개선

**베이스라인**:
팀이 공정 비교 조건으로 직접 학습한 ESPCN(RGB 입력, L1 손실). 모든 Δ의 기준이다.
_Avoid_: 기본 모델, 원본 모델, 논문 모델, 기존 모델

**Bicubic 하한**:
학습 없이 bicubic 보간만으로 만든 SR 결과. 결과 표에서 최저 기준선 역할만 하며 베이스라인이 아니다.
_Avoid_: 기본 보간, 보간 베이스라인

**개선**:
진단된 약점과 강의 개념에 근거해 베이스라인에 켜고 끌 수 있게 더한 단일 변경.
_Avoid_: 기법, 튜닝, 수정, 트릭

**핵심 개선**:
Ablation과 시드 반복으로 완전히 검증하기로 한 개선. 현재 에지 손실(A)과 Y 채널 처리(B).
_Avoid_: 주요 개선, 메인 기법

**탐색 개선**:
단독 효과만 먼저 검증하고, 결과에 따라 승격 여부를 정하는 개선. 현재 전역 잔차(C).
_Avoid_: 추가 실험, 옵션 개선, 보너스

**승격**:
탐색 개선을 핵심 개선으로 올려 다른 개선과의 조합까지 검증하기로 하는 결정.
_Avoid_: 확장, 추가 채택

**에지 손실**:
모델이 복원하는 채널(Y 채널 처리가 꺼져 있으면 RGB, 켜져 있으면 Y)에서 SR 결과와 HR 영상의 Sobel 에지 차이를 학습 목표에 더하는 개선(A).
_Avoid_: 엣지 로스, 경계 손실, 그래디언트 손실

**Y 채널 처리**:
YCbCr 색 공간에서 밝기(Y) 채널만 모델로 복원하고 색차(Cb·Cr) 채널은 bicubic으로 확대하는 개선(B). 모델 용량(파라미터 수)도 함께 줄어든다.
_Avoid_: 흑백 처리, 밝기 학습, 휘도 모델

**전역 잔차**:
bicubic으로 확대한 LR 영상에 모델이 예측한 차이를 더해 SR 결과를 만드는 개선(C).
_Avoid_: 스킵 연결, 잔차 블록, residual

**구성**:
베이스라인에 어떤 개선을 켰는지로 정의되는 비교 단위. 예: 베이스라인, +A, +B, +A+B, +C.
_Avoid_: 버전, 세팅, 모델 변형

**통제 구성**:
개선이 아니라, 어떤 개선의 효과를 여러 요인으로 나눠 보기 위해 추가하는 비교용 구성. 현재는 RGB 입출력은 그대로 두고 손실만 Y 채널에서 계산하는 Y 손실 통제(B′) 하나다.
_Avoid_: 대조군, 보조 실험, 추가 구성

**제안 구성**:
최종적으로 채택한 개선을 모두 켠 구성.
_Avoid_: 최종 모델, improved, 개선 모델

## 실험과 입증

**공정 비교 조건**:
모든 구성에서 똑같이 고정하는 학습 조건. PDF가 요구한 데이터·에폭·학습률과, 팀이 추가로 통제하기로 한 조건을 함께 가리킨다.
_Avoid_: 같은 조건, 기본 설정, 하이퍼파라미터

**실행**:
한 구성을 한 시드로 학습하고 평가하는 1회 작업. 결과 수치의 최소 출처 단위다.
_Avoid_: 실험(단독 사용), 트라이얼, 런

**시드**:
실행의 무작위성을 정하는 값. 모든 구성은 시드 0, 1, 2로 각각 실행한다.
_Avoid_: 랜덤값, 반복 번호

**파일럿 실행**:
공정 비교 조건의 실제 값(에폭 수 등)을 정하기 위한 시험 실행. 결과 표와 Ablation에 넣지 않는다.
_Avoid_: 테스트 런, 예비 실험

**평가 체크포인트**:
실행을 평가할 때 쓰는 모델 가중치. 모든 실행에서 마지막 에폭의 가중치다.
_Avoid_: 베스트 모델, 최종 모델

**Ablation**:
개선을 하나씩 켜고 끈 구성들을 비교해 각 개선의 기여를 분리해 보이는 비교.
_Avoid_: 소거 실험, 제거 실험, 비교 실험

**Δ**:
같은 테스트셋·같은 지표에서 어떤 구성의 시드 평균에서 베이스라인의 시드 평균을 뺀 값.
_Avoid_: 향상률, 개선율, 성능 차이

**시드별 Δ**:
같은 시드로 실행한 어떤 구성과 베이스라인의 테스트셋 지표 차이. 시드 0·1·2의 시드별 Δ 부호가 모두 같으면 "방향이 일관된다"고 한다.
_Avoid_: 쌍대 차이, 시드 차이

**영상별 Δ**:
같은 테스트 영상 한 장에 대해, 같은 시드끼리 어떤 구성의 지표에서 베이스라인의 지표를 뺀 값. 개선 효과가 영상 전반에서 일관된지 보는 데 쓴다.
_Avoid_: 이미지별 차이, 샘플 Δ

**진단**:
베이스라인의 SR 결과가 어디서, 어떤 식으로 틀리는지 찾는 분석. 오차 지도, 에지·평탄 영역 분리, 주파수 스펙트럼 비교, YCbCr 채널별 오차 분해로 한다.
_Avoid_: 분석(단독 사용), 디버깅, 오류 확인

**약점**:
진단으로 확인된 베이스라인의 체계적 실패 패턴. 각 개선은 약점 하나 이상을 근거로 가진다.
_Avoid_: 문제점, 한계, 버그

**실패 사례**:
어떤 구성이 베이스라인보다 나빠졌거나 기대한 효과가 나타나지 않은 영상 또는 실행. 원인 분석 대상이다.
_Avoid_: 오류, 실패한 실험

**대표 영상**:
본 실행 전에 정해진 규칙(테스트셋별로 파일럿 베이스라인의 PSNR(Y)이 중앙값인 영상과 최하위인 영상)으로 고정해, 모든 구성의 Before/After에 공통으로 쓰는 영상.
_Avoid_: 샘플 이미지, 예시 이미지

**사례 영상**:
결과가 나온 뒤 영상별 Δ에서 규칙(테스트셋별 Δ 상위·하위 영상)으로 자동 선정하는 성공 사례와 실패 사례 영상. 사람이 고르지 않는다.
_Avoid_: 베스트 컷, 골라낸 결과

**동결**:
그 이후로는 실행 결과와 코드를 바꾸지 않기로 한 시점. 보고서와 발표 수치는 동결 시점의 결과만 쓴다.
_Avoid_: 마감, 확정, 프리즈

## 지표

**Y 채널**:
ITU-R BT.601 정의(MATLAB `rgb2ycbcr`와 같은 계수, 16~235 범위)로 RGB에서 구한 밝기 성분. 학습과 평가 모두 이 정의 하나만 쓴다.
_Avoid_: 밝기, 그레이스케일, 휘도(정의 미지정)

**PSNR(Y)**:
가장자리를 배율만큼 잘라낸 SR 결과와 HR 영상의 Y 채널로 영상마다 계산한 PSNR. 테스트셋 값은 영상별 값의 평균이다.
_Avoid_: PSNR(채널 미지정), 화질 점수

**PSNR(RGB)**:
PSNR(Y)과 같은 가장자리 처리로 RGB 3채널 전체에서 계산한 보조 PSNR. Y 채널만 보면 가려지는 색 복원 차이를 드러내기 위해 함께 보고한다.
_Avoid_: 컬러 PSNR, 전체 PSNR

**SSIM(Y)**:
PSNR(Y)과 같은 채널·같은 가장자리 처리로 계산한 SSIM.
_Avoid_: SSIM(채널 미지정), 구조 유사도 점수

**에지 영역**:
가장자리를 배율만큼 잘라낸 HR 영상의 Y 채널에서, 그 영상 안의 Sobel 에지 크기 상위 일정 비율(q%)에 드는 화소들의 영역. 비율 기준이므로 모든 영상에 에지 영역이 존재한다.
_Avoid_: 경계 부분, 윤곽

**평탄 영역**:
HR 영상에서 에지 영역이 아닌 나머지 화소들의 영역.
_Avoid_: 배경, 매끈한 부분

**에지 PSNR**:
에지 영역의 화소만으로 영상마다 계산한 PSNR(Y)을 테스트셋에서 평균한 값. 에지 복원 품질을 따로 보기 위한 팀 추가 지표다.
_Avoid_: 엣지 성능, 경계 PSNR

**LPIPS**:
사람이 느끼는 지각적 차이를 근사하는 학습 기반 지표. 낮을수록 좋다.
_Avoid_: 지각 점수, 체감 화질
