# 베이스라인은 RGB 입력·L1 손실의 ESPCN으로 한다

베이스라인으로 ESPCN을 고른 이유는 세 가지다. 저해상도 공간에서 특징을 뽑고 마지막에 sub-pixel 방식으로 확대해서 가볍고, 그래서 시드 3개 × 여러 구성의 실행 예산과 라이브 데모를 감당할 수 있다. 또 업샘플링 방식이 강의 개념인 보간과 바로 연결된다.

ESPCN 원 논문은 Y 채널로 학습한다. 그런데도 **일부러 RGB 입력으로 시작한다.** Y 채널 처리를 강의 개념인 색 공간 변환에 근거한 개선(B)으로 따로 검증하기 위해서다. 이 선택을 "원 논문과 다르니 고쳐야 할 오류"로 보고 되돌리면 안 된다.

## Considered Options

- **SRCNN**: bicubic으로 먼저 확대하고 고해상도 공간에서 연산해서 느리다. 업샘플링 교체가 너무 뻔한 개선이 된다.
- **FSRCNN**: 가장 가까운 대안이었다. ESPCN과 비슷한 수준이라, PDF 예시 모델인 ESPCN을 택했다.
- **VDSR, EDSR-baseline, IMDN, CARN**: 파라미터가 수십만~백만 단위라, 3시간 상한 안에서 시드 반복을 하기 어렵다.
