# 보고서와 발표의 모든 수치는 실행 기록에서 스크립트로 생성한다

AI 에이전트가 보고서나 발표 자료를 쓸 때, 측정하지 않은 그럴듯한 수치를 만들어 내거나 오래된 실행의 수치를 섞을 수 있다. "실험을 통한 입증"이 배점의 30%이므로, 이런 수치 하나가 신뢰 전체를 깎는다.

그래서 보고서·발표·데모에 들어가는 모든 수치와 표는 다음 원칙을 따른다.

- 실행별 지표 CSV에서 스크립트로만 생성한다.
- 각 수치는 실행 ID(커밋, 구성, 시드)까지 거슬러 추적할 수 있어야 한다.
- 손으로 쓰거나 에이전트가 작성한 수치는 쓰지 않는다.

12/5 동결 이후에는 표를 다시 생성하지 않는다.
